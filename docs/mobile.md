# 手机端使用说明（iOS / 鸿蒙）

> 结论：**可以直接在手机浏览器里用**。网页应用本身就是单文件 HTML，手机浏览器打开即可；
> 但要注意「怎么把文件放进手机」和「进度能不能保存」这两件事。

---

## 一、iOS（iPhone / iPad）

### 方法 A：文件 App + Safari（最简单，可离线）

1. 用 AirDrop / 微信「文件传输助手」/ 邮件，把 **整个「考研知识点梳理」文件夹** 发到 iPhone；
2. 在「文件」App 里找到它（微信文件需先「用其他应用打开 → 存储到文件」）；
3. 点 `首页-科目选择.html` → 选「Safari」打开。

> iOS 对 `file://` 打开的网页限制本地存储，**学习进度可能不保存**，应用顶部会提示。
> 想要进度，用方法 B。

### 方法 B：电脑开热点 / 同一 Wi-Fi + Safari（推荐，进度可保存）

1. 电脑上双击 `手机访问.command`（或终端执行 `python3 启动手机访问.py`）；
2. 屏幕显示形如 `http://192.168.1.3:8765/` 的地址；
3. iPhone 连同一个 Wi-Fi，Safari 输入该地址；
4. 打开后点「分享 → 添加到主屏幕」，桌面出现图标，之后像 App 一样打开。

### 方法 C：静态托管（长期用最省心）

把文件夹上传到 GitHub Pages / Netlify / Vercel 等静态托管，得到 https 地址，手机收藏即可；https 下进度保存最稳定。

## 二、鸿蒙（HarmonyOS / HarmonyOS NEXT）

### 方法 A：文件管理 + 华为浏览器

1. 通过华为分享、微信文件、USB 或网盘，把文件夹放到手机「文件管理」；
2. 点 `首页-科目选择.html` → 选择「浏览器」打开。

> 不同版本对本地存储策略不同；若顶部提示「无法保存进度」，改用方法 B。

### 方法 B：同一 Wi-Fi + 浏览器（推荐）

与 iOS 方法 B 相同：电脑运行 `启动手机访问.py`，手机浏览器输入 `http://电脑IP:8765/`。
鸿蒙浏览器菜单中一般有「添加到桌面」。

## 三、手机上的操作方式

- 布局自动变为**上下结构**：上方卡片列表 / 下方卡片详情；
- 左上角 **☰** 打开侧栏，里面有「数学 / 408」科目切换与章节树；
- 学习中点卡片翻面，底部三个按钮对应「忘记 / 模糊 / 掌握」；
- 公式为 SVG 矢量图，双指放大不糊；超宽公式可左右滑动。

## 四、进度、主题与导入

- 学习记录**按科目分开**保存；切换科目不会丢进度。
- **主题（明亮 / 暗黑）全局共享**：在任一科目切换后，另一个科目会保持同一模式。
- 换手机 / 换浏览器时：在「学习统计 → 导出学习记录」导出 JSON，再到新设备「导入学习记录」，
  选择「合并」（保留较新记录）或「覆盖」（用文件替换本机进度）。

## 五、常见问题

**Q：微信里点开 HTML 没反应？**
微信内置浏览器常拦截本地 HTML；请「用其他应用打开」→ 选浏览器，或改用方法 B。

**Q：进度会丢吗？**
进度存在手机浏览器本地。换浏览器、清缓存、无痕模式都会丢；重要进度请导出备份。

**Q：一定要开电脑吗？**
只在「把文件传到手机」和「想要可靠保存进度」时需要；文件已在手机里时，方法 A 可完全离线使用。

**Q：两个科目会互相覆盖吗？**
不会，进度分开存储；主题是共享的，这正是为了让切换科目时观感一致。
