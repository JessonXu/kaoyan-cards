## 1. 数据结构（147 张）

### 章节地图

| 章节 | 卡片 | 定位 | 核心考点 |
|---|---:|---|---|
| 01 线性表 | 18 | 重点 | 顺序表插入/删除移动次数、单链表头插/尾插、双链表、循环链表、静态链表、双指针 |
| 02 栈、队列与数组 | 19 | 重点 | LIFO/FIFO、循环队列判空/判满/元素个数、中缀转后缀、卡特兰数、特殊矩阵压缩 |
| 03 串与 KMP | 10 | 难点 | 朴素匹配、next/nextval 的含义与手算、KMP 复杂度 |
| 04 树与二叉树 | 28 | 难点 | 二叉树性质、完全二叉树编号、遍历与构造、线索树、哈夫曼、AVL、并查集 |
| 05 图 | 22 | 难点 | 邻接矩阵/邻接表、DFS/BFS、Prim/Kruskal、Dijkstra/Floyd、拓扑排序、关键路径 |
| 06 查找 | 20 | 重点 | 折半查找判定树、分块查找、B/B+ 树、散列表冲突处理、BST/AVL |
| 07 排序 | 23 | 重点 | 八大排序的复杂度/稳定性/适用场景、堆、归并、基数、外部排序 |
| 08 算法设计与易错 | 6 | 高频 | 答题模板、O(n)/O(1) 技巧、链表/树/图边界 |

### 重点难点

1. **复杂度不是背结论，要会数循环。** 顺序表插入平均移动 n/2、删除平均移动 (n−1)/2；单链表找倒数第 k 个用双指针；链表逆置用三指针。
2. **栈队列的“判空/判满/个数”是选择题高频点。** 循环队列牺牲一个单元：空 front==rear，满 (rear+1)%MaxSize==front，个数 (rear−front+MaxSize)%MaxSize；不牺牲单元时用 tag/count。
3. **KMP 是典型难点。** 记住 next 是“最长相等前后缀长度 + 1”，next[1]=0、next[2]=1；nextval 用来跳过相同字符的再次失配。手算 ababaaab 的 next = 0 1 1 2 3 4 2 2。
4. **树的性质要会推。** n0=n2+1、完全二叉树高度 ⌊log₂n⌋+1、叶子数 ⌈n/2⌉、n 个结点二叉链表空指针 n+1；前序+中序或后序+中序可唯一构造，前序+后序不行。
5. **图的应用题要分清算法。** Prim 适合稠密图 O(n²)，Kruskal 适合稀疏图 O(e log e)；Dijkstra 不能处理负权，Floyd 可处理负权但不能有负环；关键路径是 AOE 网中最长路径。
6. **查找要抓“判定树”和“ASL”。** 折半查找判定树高度 ⌊log₂n⌋+1，失败结点 n+1；B 树/B+ 树的分裂、合并、叶子链表是简答题常客；散列要会算装填因子和线性探测的堆积。
7. **排序要形成表格记忆。** 稳定：插入、冒泡、归并、基数；不稳定：希尔、快排、选择、堆。快排平均 O(n log n)、最坏 O(n²)，平均空间 O(log n)、最坏 O(n)；归并空间 O(n)；堆排序建堆 O(n)、总体 O(n log n)。
8. **算法设计题按“思想 → 代码 → 复杂度”作答。** 先处理空表、单结点、头尾、k 超长等边界，再写核心循环；能 O(1) 空间就不要开数组。

### 最容易丢分

- 链表题断链：插入/删除前没有保存后继。
- 循环队列的 front/rear 初始值与元素个数公式混用。
- 二叉树遍历序列构造时，左右子树区间切错。
- 图算法只背名字，不会写 visited、距离数组和松弛条件。
- 排序题把“比较次数”和“移动次数”混为一谈。

## 2. 计算机组成原理（122 张）

### 章节地图

| 章节 | 卡片 | 定位 | 核心考点 |
|---|---:|---|---|
| 01 系统概述与性能 | 13 | 重点 | 冯·诺依曼结构、字长、CPI/MIPS、执行时间、端序、性能指标 |
| 02 数据表示与运算 | 24 | 难点 | 原/反/补/移码、溢出判断、IEEE 754、浮点加减乘除、乘除法、校验码 |
| 03 存储系统 | 34 | 难点 | SRAM/DRAM、刷新、位/字扩展、Cache 映射/替换/写策略、虚存、TLB、页表 |
| 04 指令系统与 CPU | 28 | 难点 | 指令格式、寻址方式、RISC/CISC、指令周期、数据通路、微程序、流水线 |
| 05 总线与 I/O | 22 | 重点 | 总线分类/仲裁/定时、I/O 编址、程序查询、中断、DMA、通道、磁盘、RAID |

### 重点难点

1. **性能计算是必拿分。** 执行时间 = 指令数 × CPI × 时钟周期，MIPS = 主频/(CPI×10⁶)；平均 CPI 按各类指令比例加权。
2. **补码与溢出。** n 位补码范围 −2^(n−1) ~ 2^(n−1)−1；加减法溢出看“最高位进位 XOR 次高位进位”；双符号位 01 正溢、10 负溢。
3. **IEEE 754 要会拆位。** 单精度 1+8+23、偏置 127；双精度 1+11+52、偏置 1023；规格化尾数隐含最高位 1。阶码全 0/全 1 对应 0、非规格化数、∞、NaN。
4. **浮点运算顺序固定。** 对阶（小阶向大阶看齐）→ 尾数求和 → 规格化 → 舍入 → 溢出判断；乘除则是阶码相加/减、尾数乘/除。
5. **存储扩展是计算题核心。** 芯片数 = (总容量/单片容量) × (总字长/单片字长)；字扩展靠片选，位扩展靠数据线并联。注意地址线、数据线、片选译码。
6. **Cache 是组成原理最大的难点。** 直接映射地址 = tag + 行号 + 块内地址；组相联 = tag + 组号 + 块内地址；写直达/写回、写分配/非写分配要会搭配。
7. **虚拟内存要串起来。** 虚地址 → 虚页号 + 页内偏移 → 查 TLB/页表 → 物理页号 → 物理地址；缺页由 OS 处理；多级页表是为了节省页表空间。
8. **流水线要会画时空图。** 理想加速比 S=nk/(k+n−1)，吞吐率 TP=n/((k+n−1)Δt)；结构/数据/控制冒险及转发、停顿、分支预测等对策要能对应。
9. **I/O 方式按 CPU 参与度排序：** 程序查询 → 中断 → DMA → 通道；DMA 以数据块为单位、周期挪用、不切换程序；中断需要保存现场和断点。

### 最容易丢分

- Cache 地址位数算错：行号/组号/块内地址的位数与 2 的幂次混淆。
- 浮点数对阶方向反了，或规格化时阶码加减方向错。
- 存储芯片扩展只算容量，不算字长/位宽。
- 流水线加速比直接写成 k，忽略填充时间。
- 中断与 DMA 的“是否切换程序”“传送单位”混淆。

## 3. 操作系统（125 张）

### 章节地图

| 章节 | 卡片 | 定位 | 核心考点 |
|---|---:|---|---|
| 01 操作系统概述 | 13 | 重点 | 四大特征、并发/并行、系统调用、内核态/用户态、中断/异常、微内核 |
| 02 进程、线程与调度 | 24 | 重点 | PCB、三状态、线程共享/私有、IPC、FCFS/SJF/RR/优先级/MLFQ、周转时间 |
| 03 同步与互斥 | 20 | 难点 | 临界区、PV 语义、生产者—消费者、读者—写者、哲学家、管程 |
| 04 死锁 | 10 | 重点 | 四个必要条件、预防/避免/检测/解除、银行家算法、资源分配图 |
| 05 内存管理 | 23 | 难点 | 分区、分页/分段/段页式、页表、TLB、置换算法、缺页、抖动、工作集 |
| 06 文件管理 | 18 | 重点 | 逻辑/物理结构、目录、FCB/inode、索引分配、空闲空间、硬/软链接 |
| 07 I/O 管理 | 16 | 重点 | I/O 层次、SPOOLing、缓冲、磁盘访问时间、磁盘调度、RAID |

### 重点难点

1. **进程与线程的“单位”要分清。** 进程是资源分配单位，线程是 CPU 调度单位；线程共享地址空间、全局变量、打开文件，私有 PC、寄存器、栈、TID。
2. **调度算法要会画甘特图。** 周转时间 = 完成 − 到达；带权周转 = 周转/服务；等待 = 周转 − 服务。SJF 可能饿死长作业，RR 时间片过大退化为 FCFS、过小切换开销大。
3. **PV 操作是 OS 最大难点。** P：S=S−1，若 S<0 阻塞；V：S=S+1，若 S≤0 唤醒。信号量负值的绝对值 = 等待进程数。
4. **生产者—消费者先 P(empty/full)，再 P(mutex)。** 顺序反了会在缓冲区满/空时死锁；多个生产者/消费者仍需要 mutex 保护缓冲区。
5. **死锁四个条件缺一不可。** 预防是破坏条件；避免用银行家算法判断安全状态；检测用资源分配图化简；解除靠剥夺、撤销、回滚。
6. **分页与分段要对比记忆。** 分页是物理划分、定长、透明；分段是逻辑划分、变长、可见；段页式 = 段号 + 段内页号 + 页内偏移。
7. **页面置换与缺页率。** OPT 理论最优但不可实现；FIFO 可能有 Belady 异常；LRU 不会；缺页率 = 缺页次数/访问次数；抖动是物理块严重不足。
8. **文件物理结构三选一。** 连续分配支持随机访问但难扩展；链接分配用 FAT 可随机访问；索引分配易扩展但索引块占空间。inode 不含文件名。
9. **磁盘访问时间 = 寻道 + 旋转 + 传输。** SSTF 可能饿死远端请求；SCAN 单向服务后折返；C-SCAN 只单向服务、返回不服务，等待更均匀。

### 最容易丢分

- P/V 顺序写反，或信号量初值设错。
- 把“并发”和“并行”、“阻塞”和“挂起”混为一谈。
- 页表项数/页表大小/物理地址位数计算混淆。
- 文件索引题忘记直接块、一级/二级/三级间接的逐级相乘。
- 磁盘调度只看总移动距离，忽略当前磁头位置和方向。

## 4. 计算机网络（105 张）

### 章节地图

| 章节 | 卡片 | 定位 | 核心考点 |
|---|---:|---|---|
| 01 体系结构 | 11 | 重点 | OSI/TCP-IP、协议/服务/接口、封装、电路/报文/分组交换、时延 |
| 02 物理层 | 11 | 重点 | 波特率/比特率、奈氏/香农、曼彻斯特编码、复用、传输介质 |
| 03 数据链路层 | 20 | 难点 | 组帧、CRC、海明码、停等/GBN/SR、CSMA/CD/CA、以太网、交换机/VLAN |
| 04 网络层 | 23 | 难点 | IPv4、分片、子网/CIDR、ARP/DHCP/ICMP/NAT、RIP/OSPF/BGP、IPv6 |
| 05 传输层 | 21 | 难点 | UDP/TCP、三次握手/四次挥手、可靠传输、流量控制、拥塞控制、端口 |
| 06 应用层 | 12 | 重点 | DNS、HTTP、FTP、SMTP/POP3/IMAP、DHCP、默认端口 |
| 07 综合与计算 | 6 | 高频 | 子网划分、吞吐率、发送时延、设备层次、协议对比 |

### 重点难点

1. **分层与封装是框架。** 每层加首部/去首部，PDU 依次为比特、帧、分组、报文段、报文；交换机隔离冲突域，路由器隔离广播域。
2. **奈氏与香农不要混。** 奈氏：理想无噪声，C=2W log₂V；香农：有噪声，C=W log₂(1+S/N)；dB 要先换成比值 S/N=10^(dB/10)。
3. **滑动窗口是链路层核心。** 停等利用率 U=T_d/(T_d+RTT)；GBN 发送窗口 2^n−1、接收窗口 1；SR 发送窗口 2^(n−1)、可缓存乱序帧。
4. **CSMA/CD 与 CSMA/CA。** 有线以太网“边发边听”，最小帧长由 2τ×数据率 决定；无线局域网难以检测冲突，采用避免/预约/ACK。
5. **IP 地址计算是必考。** 子网划分从主机号借位；CIDR 取公共前缀聚合；转发按最长前缀匹配；分片除最后一片外，数据长度必须是 8 的倍数。
6. **TCP 连接管理。** 三次握手同步序号、防止失效请求；四次挥手因为 TCP 全双工；TIME_WAIT 等 2MSL，确保最后 ACK 到达并让旧报文消失。
7. **TCP 拥塞控制。** 慢开始指数增长；拥塞避免线性增长；3 个重复 ACK 触发快重传/快恢复；超时则 ssthresh 减半、cwnd=1。
8. **应用层抓协议+端口。** HTTP 80、HTTPS 443、FTP 21/20、SMTP 25、POP3 110、IMAP 143、DNS 53、DHCP 67/68、SSH 22、Telnet 23。
9. **综合题常考“单位”。** 带宽 Mbit/s、时延 ms、窗口 KB、RTT s 要统一；吞吐率 = 窗口/RTT（忽略拥塞时）。

### 最容易丢分

- 把“发送时延”和“传播时延”混为一谈。
- 子网划分借位后，网络地址/广播地址/可用主机数算错。
- TCP 序号和确认号的含义颠倒。
- 拥塞窗口在超时和 3 个重复 ACK 两种情况下处理混淆。
- 协议端口、传输层协议（TCP/UDP）记混。

## 5. 怎么用这四个卡组

1. **分别导入四个 .apkg 文件。** 每个文件是一个独立科目卡组，内含「00 复习导航 + 章节子卡组」。  
2. **如果之前导入过旧的《408考研记忆卡.apkg》**，建议先在 Anki 中删除旧卡组，再导入这四个分科包，避免同一知识点出现两套卡片。
3. **按标签筛选：**  
   - 难点：**408::标记::难点**  
   - 高频：**408::标记::高频**  
   - 某科某章：**408::数据结构::图**、**408::操作系统::同步与互斥**
4. **每天新卡 30–50 张，复习优先。** 408 四科并行时，建议每天“数据结构 + 组成原理”各一组，操作系统和网络交替；每周做一次综合题。
5. **卡片只负责“回忆”，不替代“手写”。** 算法设计、Cache 计算、PV 操作、子网划分必须自己在纸上完整写一遍，再回来看卡。
