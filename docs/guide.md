# 考研知识点梳理 · 网页应用使用说明

> 两个科目各是一个 **单文件、离线、双击即用** 的网页应用：
>
> - `首页-科目选择.html` —— 科目选择入口
> - `数学/考研数学-知识卡片.html` —— 数学（253 张）
> - `408/408-知识卡片.html` —— 408（495 张）
>
> 打开方式：双击对应 HTML（推荐 Chrome / Edge / Safari），无需安装、无需联网、无需启动服务器。

---

## 1. 科目选择

- 首页提供「数学」「408」两张科目卡，点击进入对应应用；
- 应用左侧栏顶部也有 **数学 / 408** 两个切换按钮，可随时跳转；
- 每个科目的学习进度**独立保存**（localStorage 键名按科目标识区分），互不影响。

## 2. 应用里的三个页面

| 页面 | 能做什么 |
|---|---|
| **卡片浏览** | 左侧「科目 → 章节」卡组树，中间卡片列表，右侧完整卡片；支持搜索、类型筛选、`j/k` 上下切换 |
| **开始学习** | 选卡组 → 逐张翻卡 → 自动记录；按 1→2→4…天安排下次 |
| **学习统计** | 累计复习、掌握率、待复习；各章节掌握度；14 天热力条；知识串联地图 |

408 应用的卡组树按四科展开：数据结构、计算机组成原理、操作系统、计算机网络；每科下面是章节。
数学应用按高等数学、线性代数、串联总表展开。

## 3. 快捷键

| 键 | 作用 |
|---|---|
| `Space` / `Enter` | 学习中：显示答案 |
| `A` / `S` / `D` | 学习中：忘记 / 模糊 / 掌握 |
| `1` / `2` / `3` | 全局切换：浏览 / 学习 / 统计 |
| `j` / `k` 或 `↑` / `↓` | 浏览时切换上/下一张 |
| `/` | 聚焦搜索框 |
| `4` | 打开算法动画库 |
| `t` | 夜间模式 |
| `Esc` | 学习页退出本轮；搜索框失焦 |

## 4. 复习规则

翻卡后按三个按钮评分（快捷键 `A` / `S` / `D`）：

| 评分 | 含义 | 下次出现 |
|---|---|---|
| **A 忘记** | 完全没想起来 | 4 分钟后重学，熟练度下降 |
| **S 模糊** | 想起来但不熟 | 首次 30 分钟，之后按 1.15 倍延长 |
| **D 掌握** | 能完整复述 | 首次 1 天，之后按熟练度 ×2.5 左右延长 |

- `1 / 2 / 3` 是全局页签（浏览 / 学习 / 统计），不会与评分冲突；
- 每次评分后，左侧科目与章节的「已学 / 总数」立即刷新。

## 5. 随机学习

「开始学习」页提供「随机学习 · 20 张」：可按数据结构、计组、操作系统、计网单科随机，也可「全部 408」随机；数学端同理。

## 5. 学习建议

**数学**

1. 第一轮：高数按 7 章顺序刷，线代按「秩」主线刷；
2. 第二轮：只刷到期卡，统计页掌握度 < 60% 的章节回炉；
3. 建网：单独刷「串联总表」，用统计页的串联地图逐条复述。

**408**

1. 选择题：四科按章节过卡，保证覆盖面；
2. 综合题：树/图算法、Cache、页表、子网划分、TCP 拥塞窗口必须手算；
3. 算法题：按“思想 → 代码 → 复杂度”模板作答，先处理边界；
4. 冲刺：用类型筛选看「高频」「难点」「易错」标记的卡。

## 6. 主题与科目切换

- **主题全局共享**：在数学里切到暗色，切到 408 仍然是暗色；反之亦然。
- **进度按科目独立**：切换科目不会清空或覆盖另一科的记录。
- **自动保存**：每次翻卡立即写入本机；切换页面前会强制落盘，右下角出现「✓ 已保存」。

## 7. 云同步（GitHub）

「学习统计 → 云同步」可把学习记录自动写到 GitHub，实现多设备同步：

1. 建一个 Fine-grained token：仓库选 `JessonXu/kaoyan-cards`，权限 **Contents: Read and write**；
2. 在面板填仓库、分支（默认 `sync-data`）、文件路径（默认 `sync/study-records.json`）、设备名称和 Token；
3. 点「保存并同步」。之后每次评分/导入会自动同步（约 1.6 秒防抖）；
4. 每条记录都会带 `device` 与 `updatedAt`，云端文件里还有设备列表和最近更新日志；多设备冲突时按更新时间取较新者。

> 同步写入独立分支 `sync-data`，不会触发 Pages 重新构建；Token 只存在本机浏览器。
> 公开仓库中的学习记录是可见的，介意的话请单独建一个私有仓库用于同步。

## 8. 数据与备份

- 学习记录在浏览器 localStorage，按科目分开保存。
- 「学习统计 → 导出学习记录」下载 JSON；换电脑可留档参考。
- **「导入学习记录」**支持两种方式：
  - **合并到本机**：新增缺失卡片，同一张卡以“最近复习”的记录为准，不会删除本机记录；
  - **覆盖本机进度**：先清空本机记录，再写入文件内容（适合换设备后完整迁移）。
- 导入前会显示预览（识别多少张、新增多少张、更新多少张），确认后才生效。
- 清空浏览器站点数据会丢失进度，重要进度请定期导出。

## 9. 常见问题

**Q：双击后空白？** 用 Chrome 打开；确认文件未被压缩软件改写。
**Q：手机上能用吗？** 可以。把 HTML 发到手机，用浏览器打开；布局自动切为上下结构，左上角 ☰ 展开卡组。
**Q：还需要 Anki 吗？** 不需要。`anki卡组/` 里的 `.apkg` 是给仍想用 Anki 的人备用的，内容与网页应用同源。
